從書的一章到成片：全部步驟

2026-11-07 整理。依據 production_process.md（2026-11-04 逐步討論稿）、production_sop.md、../WORKFLOW.md、EP1 實作紀錄，以及 2026-11-06～07 的背景、追逐、景別實驗。

狀態圖例

  • ✅ 討論定案：跟使用者逐步討論過，做法定了。
  • 🧪 做過、沒定案：EP1 實際做過，或做過實驗，但做法還沒跟使用者定案。
  • ⬜ 沒討論：從來沒討論過，下面寫的是我的建議。

工具欄怎麼看

  • 「給你用」是我做給使用者操作的介面，例如網頁、編輯器。
  • 「我用」是我自己跑的程式，使用者不用碰。

不做的步驟。 恐龍穿越系列的流程有「收集論文資料、做命題卡、排季集數」三步，本專案不做：書的內容直接改寫成旁白，不考證（CLAUDE.md）。

順序不能倒。 劇本 → 分析 → 地圖 → 走位 → 鏡頭 → prompt → 畫圖。前面一改，後面就要重做。EP1 v5 邊畫邊改劇本，結果全部重畫。

1. 選章 ✅

  • 誰： 你。
  • 怎麼做： 從《How to Survive History》挑一章，原文放在 source/how_to_survive_history/chNN_*。前三章對應 EP1～EP3。

2. 讀章、列重點 🧪

  • 誰： 我整理，你看。
  • 怎麼做： 我讀完整章，列出可以講的內容：事件順序、數字、危險點、好笑的地方。只照書上的講，不另外查資料。
  • 沒定的： 要列到多細、要不要做成固定格式的清單，都沒討論過。EP1 是直接從書跳到大綱。

3. 套系列設定 ✅

  • 已經定好的設定：
  • 布朗博士，加上不想畢業又沒錢的資工延畢生來打工。
  • 每集博士都賴帳。
  • 主角老是忘了帶生存指南。
  • 角色發聲： HERO、PROF 用林克式發聲，有聲音、沒台詞，故事全靠旁白和反應音。
  • 畫風： v2 粗手腳火柴人，皮膚純白，不設定種族。

4. 大綱 ✅

  • 誰： 我提案，你確認。
  • 故事架構，每集固定： 冷開場 → 博士有工作 → 穿越 → 故事 → 回家 → 賴帳 → 預告。
  • 每段要寫： 發生什麼、這段的目的、用到書上哪個重點。
  • 科普比例： 定為 30%，用秒數算。量法還沒定。
  • 對照： 寫完逐段對 craft.html 的「故事結構」「張力與情緒」兩類。
  • 產出： storyboard/outline_vN.json。

5. 寫故事 ✅

  • 誰： 我寫。
  • 怎麼做：
  • 照大綱寫成完整故事。
  • 旁白用自己的話改寫，不照念原文。
  • 角色只有反應音。

6. 審故事 ✅

  • 誰： 你審。來回好幾次，直到定案。
  • 怎麼做： 你修邏輯、場景、道具、旁白。每改一版，我做一頁新舊左右對照給你看（make_script_v6.py 產生 compare_v5_v6.html）。

7. 分鏡清單＋旁白（定稿點）✅

  • 誰： 我切格，你確認定稿。
  • 切格規則（照畫面切，旁白配畫面）：
  • 發生新的動作或事件。
  • 主角換人，包括反應鏡頭。
  • 地點或時間變了。
  • 要看清楚的東西需要換景別（眼神、道具）。
  • 講一個新的知識點。
  • 一格旁白超過約 10 秒，就拆開。
  • 每格欄位： 畫面發生什麼、旁白逐字、聲音、長度、主題、主角／配角、景別初定、分類（科普／劇情／搞笑）。
  • 道具時間線： 整集另外列一張，寫每個道具在哪一格出現、哪一格不見。
  • 聲音： 分旁白、反應音、音效、環境音四種。跟畫面有關的聲音這一步就定。
  • 旁白定稿後能怎麼改：
  • 可以直接改的：換說法但意思不變；每格長度增減 2 秒以內。
  • 要退回這一步的：改到畫面上的人、物、動作、位置。
  • 產出： script_vN.md。
  • 給你用： 分鏡表網頁。

8. 每格分析 ✅

  • 誰： 我寫，你確認。
  • 每一格回答三題：
  • 主題：這一格要讓觀眾知道什麼。
  • 主角：可以是人、恐龍，也可以是一個東西。
  • 配角：畫面裡還有誰、還有什麼。
  • 由這三題推出入鏡範圍：全身、半身、局部或特寫。
  • 產出： shot_analysis_vN.md，分鏡表上每一格都會顯示。

9. 場景地圖 ✅

  • 誰： 我畫初稿，你在編輯器裡改。
  • 給你用： 地圖編輯器。執行 cd episodes/<集> && python3 storyboard/map_editor.py，然後開 http://127.0.0.1:8766/。
  • 怎麼做：
  • 故事有幾個地點，就畫幾張地圖。地圖跟著地點走，不跟著段落走。
  • 地圖是網格，一格 2 公尺。
  • 「區域」用塗色畫，「物件」要編號。
  • 每個區域、物件都標高度。
  • 每張地圖都寫 outside，交代東南西北四個方向的遠景。
  • 地圖上沒有的東西，畫面裡就不能出現。
  • 產出： maps/<id>.json。存檔前，舊版會自動備份到 maps/history/。

10. 角色位置（走位）🧪

  • 誰： 我排初稿，你改。
  • 給你用： 同一個地圖編輯器。
  • 每個角色要記：
  • 所在格子。
  • 身體朝向，只用 8 個方向。
  • 視線。
  • 移動路線。
  • 這一格畫的是起點、中間還是終點那一瞬間。
  • 動作，中英文各一份。
  • 自動調整： 有警告的格子，用 fix_blocking.py 在附近重新找鏡頭位置。
  • 沒定案的地方： 2026-11-05 你說過「張力要看圖才判斷得出來」。所以目前的做法是：先把警告修到沒有，畫出來看了，再回頭改。這個來回的流程還沒定。

11. 鏡頭 🧪

  • 誰： 我排初稿。你通常只看鏡頭的位置、朝向和景別。
  • 給你用：
  • 地圖編輯器：灰色扇形是拍得到的範圍，右上角是這一格的檢查結果。
  • 景別測試頁：s003-shot-tests
  • 要定的項目： 位置、朝向、高低、景別、焦段。
  • 景別： 名稱以 banana_nano_shot_types_and_camera_angles_guide.md 為準，prompt 只寫英文名。
  • 2026-11-07 測試的結論（只代表 S00-3 這一幕）：
  • 景別百分比模型不照做。十級實際只分得出約六級：01–03、04、05、06–07、08、09。第 10 級失敗。
  • 相機角度只有 High angle 有效。Slight low、Low 寫了等於沒寫。
  • 遠景要配 High angle，人才會縮得夠小。
  • 大恐龍和人同框： 鏡頭以主角為準，大恐龍只露半身，絕不縮小。
  • 沒定案的地方： 編輯器裡景別、角度的選項，還沒依這次測試改成只留有效的幾個。

12. 設定圖 ✅

  • 誰： 我寫 prompt，你挑圖。
  • 時機： 放在鏡頭之後。先知道每一格怎麼拍，才知道要哪些角度、表情、道具。
  • 要做的設定圖：
  • 角色：HERO、PROF、恐龍。
  • PROPS：重複出現的道具。
  • 固定地點：例如 LAB。
  • 1 對 1 比例圖 PAIR：只有 HERO 和那一隻恐龍。
  • 比例數字只有一份： build_scale_pairs.py 產生比例圖時，同時寫出 heights.json，prompt 只讀這一份。
  • 比例圖不叫 Flow 畫，由程式從設定圖裁切拼成。
  • 設定圖上不要畫會變的道具。 例如畫了手環，Flow 每一格都會照抄。

13. 空景 🧪

  • 誰： 我畫，你挑。
  • 目的： 每個地點先畫一張沒有角色的遠景，之後每一格都附這張，背景才接得起來。
  • 怎麼做： 1. plates.py：畫空景。 2. scale_plate.py：畫量尺版，讓角色站在空景裡，用來量角色該畫多大。 3. remove_chars.py：把量尺版的角色拿掉，變回空景。
  • 已知問題： Flow 會把整張空景原樣搬進每一格，所以景別出不來。
  • 補救實驗： 換方向用「連戲檢查清單」；往後退用深度圖縮放再補畫（dolly.py）；指定站位用貼圖法。
  • 實驗紀錄： bg-experiments
  • 沒定案： 要不要正式放進流程、放在哪一步。

14. 寫 prompt ✅

  • 誰： 我。由程式從地圖產生，不手寫個別格。指令是 map_prompt.py <地點>。
  • 每一格輸出三樣：
  • 參考圖清單。
  • 中文 prompt 給你看，英文 prompt 貼進 Flow。
  • 自動檢查結果。
  • 規則：
  • 每個角色都要寫畫面占比。
  • 大小只講一次，照附上的比例圖。
  • 不准加你沒要的字。
  • 失敗就整段重寫，不准疊補丁句。
  • 參考文件的範例句不准抄。
  • 每次產生後，掃一次有沒有混進中文。

15. Flow 畫圖 🧪

  • 誰： 我操作。你同意過可以自動操作，條件是滑鼠動作要像人手，被擋就停。
  • 怎麼做： agent.py draw <格> 會依序附圖、貼 prompt、送出、等圖出來，一次出 4 張。
  • 安全規則：
  • 不照固定座標點下載鍵或垃圾桶鍵。
  • 圖庫頁不按 ⌘A＋刪除。
  • 不永久刪除。
  • 你喊停就停。
  • 沒定案： 一次送多少格、每格重畫幾次才放棄。

16. 挑圖、驗收、補救 ✅

  • 誰： 我挑，你抽查。
  • 給你用： 挑圖頁（EP1 用的是 shots/variants/pick.html）、十一種表現法頁。
  • 挑圖： 先逐項寫出檢查結果，再決定。檢查項目：動作、位置、長相、穿戴、比例、膚色、字。都合格時，選戲劇張力強的那張。
  • 驗收：
  • 尺寸不憑感覺估，交給 Codex 對照比例圖。
  • Codex 只問單格，不拿整份去問。
  • 補救只用兩種： 恐龍只露出一部分，或鏡頭拉遠。不用 Flow 的修改功能。
  • 候選圖： 不丟垃圾桶、不改名，等你挑定。

17. 下載 🧪

  • 誰： 你決定解析度。說用哪個，就只用那個。
  • 怎麼做： 執行 download_all.py vN [1K]。下載前，舊版移到 old_roundN/，不刪。
  • 下載後檢查：
  • 張數。
  • 哪幾張是 1K。
  • Flow 裡有沒有圖被丟進垃圾桶。

18. 分鏡表＋審查 🧪

  • 誰： 你看完再決定改哪些。
  • 給你用： 分鏡表網頁（build_board_vN.py 產生 index_vN.html），每一格有圖、分析、走位圖、旁白、prompt。
  • 審查： 把同一份資料交給另一個 Claude 和 Codex，兩份意見合併成一張表，依嚴重度排序。
  • 畫壞了退回哪一步： 下表是建議，還沒討論過。

19. 動畫（扣點）⬜

  • 舊流程（WORKFLOW 步驟 6）有這一步：用場景圖當第一格，Omni Flash 生 10 秒，先 360p 試、再 720p 正式。
  • 2026-11-04 的新流程沒有這一步，EP1 v5 之後的成片全部是靜止圖加運鏡。
  • 要討論：
  • 要不要做動畫。
  • 哪幾格做。
  • 點數預算。
  • 放在配音之前還是之後。
  • 誰決定： 你，因為要花點數。

20. 旁白配音 🧪

  • 誰： 我做，你聽。
  • 怎麼做： 在 Studio 上用 GPT-SoVITS sichu2 念。每句念 3 遍，用 Whisper 挑最好的一遍，再轉成 RVC 女聲。指令是 scripts/studio_sichu_narr.sh。
  • 備案： cuba001 上的 lin 聲音，或 Azure 念完再轉 RVC。
  • 要人耳聽： Whisper 會把國字和阿拉伯數字的差別也算成錯字，分數不能全信。
  • 沒定案： 用哪個聲音當正式版。

21. 音效 🧪

  • 誰： 我做，你聽。
  • 環境音： 每個地點做一段，用 MMAudio 看畫面生成。
  • 事件音效： 要對準時間點。真實的聲音用免費音效庫，恐龍這類用 TangoFlux 生成。
  • 已測： 2026-11-06 用 MMAudio 和 TangoFlux 各做了全片一版。Stable Audio Open 效果太差，不用。
  • 待試： HunyuanVideo-Foley、ThinkSound。
  • 沒定案： 用哪個模型、事件音效怎麼對時間。

23. 運鏡＋組片＋字幕 🧪
