送進 Flow 的 prompt 是怎麼組出來的

一格畫面的英文 prompt，從第 13 步到第 16 步經過哪些人、哪些程式，每一段是誰寫的。以 EP1-new 現在的程式為準。

產生日期：2026-11-25

總覽：一個 prompt 由三個來源接起來

誰哪一步寫什麼
分鏡模型（Claude CLI）第 13 步角色、狀態、動作、表情、景別、鏡頭方向、角度；裡面夾著 request 規定照抄的固定句和實測句
背景模型（Claude CLI）第 15 步Background: 開頭那段——對著哪片景、看得到什麼、在畫面哪裡、光從哪來；也決定附哪些參考圖
程式照搬（內容是 Claude 事先寫的）第 15 步組檔比例圖說明句（附 PAIR2_ 時）；地圖檔裡的天空和地形描述（sky、look）

一步一步

第 13 步　分鏡 request

誰做：程式組 request（make_scene_request.py），送 Claude CLI（reqlog 有紀錄），回覆存 docs/requests/<場>_reply_claude.json

給模型的

  • 這場的劇本和旁白、地圖說明、角色和狀態
  • 規定：畫風句、膚色句照固定寫法寫
  • 實測句表（docs/shot_spec.json）：景別、水平方位、角度三項直接用表上的英文句子，只准把句子裡的 HERO、trail、TEEN 換成這一幕的東西

模型回的

  • 每格一筆：景別 shot_size、水平方位 azimuth、角度 angle、構圖 composition、畫面方向 screen_direction、動作 action、相機 camera、入鏡角色 cast……
  • 一整串英文 prompt（prompt 欄）

只有 prompt 這一欄會進送 Flow 的 prompt。構圖、畫面方向這些欄位不會組進去。回覆是一整串，沒有分段；哪幾句是照抄實測句，回覆裡沒有欄位可以分辨。

翻中文（給分鏡表看）

誰做：translate_prompts.py 送模型翻譯，存 <場>_prompt_zh.json

給模型的

  • 第 13 步模型寫的英文 prompt

模型回的

  • 中文翻譯

只給分鏡表顯示，不會送 Flow。

第 15 步　背景 request

誰做：程式組 request（make_bg_request.py build），送 Claude CLI（send），回覆存 <場>_bg_reply_claude.json；check 合格的合進 <集>_bg_hand.json

給模型的

  • 程式先算好、每格附上：sun＝太陽在相機哪一邊（sun_side.py）；view＝畫面左／中／右各看得到地圖上哪些地形和物件、哪些看不到（view_side.py）
  • 每格的鏡頭資料：鏡頭號、遠景備份對哪格、景別、角度 angle、相機（格子、高度、對準誰、距離）、入鏡角色、動作
  • prompt 只在兩種情況附上：這場有空景圖，或 prompt 裡有手機、相機、電擊槍等道具
  • 這場的角色和狀態、地圖說明、可用參考圖清單、15 條規定

沒有給：水平方位 azimuth、構圖 composition、畫面方向 screen_direction。

模型回的

  • 每格 zh、en（Background: 開頭）、refs（要附的參考圖）
  • redo：鏡頭資料跟地圖或參考圖衝突、背景救不回來的格

規定第 11 條（原則十）：天空、地面、道路、河流的顏色和樣子不用寫，組檔時程式會照地圖補上。

第 15 步　組檔

誰做：assemble_v2.py（只搬運），輸出 <場>_draw_reply_claude.json

順序

  1. 從第 13 步模型的 prompt 開始。
  2. 附了比例圖 PAIR2_<名字>、而且 prompt 裡有 HERO：在「Shot size:」前面插一句比例圖說明（One of the attached images is a scale chart …）。
  3. refs 有 ENV 開頭的環境圖：直接停下（原則十不准附）。
  4. 附了空景圖 PLATE_ 或實驗室牆面圖：拿掉畫風句，把背景句移到最前面；這種格不補地圖描述，到這裡結束。
  5. 其他格：後面接背景模型的英文，再接地圖描述——地圖的天空 sky，加上 view 算出看得到的地形各自的 look（算不出視野就補整張地圖有的；插圖格不補）。
  6. 參考圖＝背景模型的 refs。

同時記下 prompt_model（第 13 步原文）、bg_en、bg_zh、env_look（補上的地圖描述），分鏡表從這裡讀。

第 16 步　畫圖

誰做：flowbot/scene_run.py

順序

  1. 參考圖名換成 Flow 上實際的檔名（scene_draw.FLOW_NAME，例 ENV_DUSK → ENVFULL_DUSK）。
  2. prompt 原樣貼上（連續空白壓成一個），附圖、送出。
  3. 存 prompt.txt、refs.json 在畫圖資料夾；畫完數 Flow 圖片頁的附圖縮圖，張數不對就停。

這裡不改 prompt 內容。

分鏡表上顯示的

誰做：make_storyboard_report.py

順序

  1. 英文：組檔後的 prompt（draw_reply 的 prompt）。
  2. 中文：第 13 步 prompt 的中文翻譯＋比例圖說明的中文＋背景模型的中文。

已知問題（2026-11-25）：中文沒有接上組檔補的地圖描述，英文有。還沒修。

例子：EP1N-01-01（改版 2 重畫、粗剪 v4 用的那張）

改過的地方

日期改了什麼
2026-11-19新流程：分鏡模型寫 prompt，背景另外一個 request，程式只負責接起來。
2026-11-21附環境圖 ENV 時，組檔加一句環境圖說明（One of the attached images is an environment reference … do not copy its layout）。這句是 Claude 寫在 assemble_v2.py 的固定句，不是模型寫的。附比例圖時加比例圖說明句（原則七）。
2026-11-21sun、view 改由程式算好給背景模型（原則八）。
2026-11-22地標參考圖和它的說明句：Claude 逐格決定、直接加進畫圖檔（EP1N_landmarks_apply.json），沒有經過背景模型。
2026-11-24空景圖、實驗室牆面圖：背景句移到最前面、拿掉畫風句。
2026-11-25原則十：不附環境圖，環境圖說明句不再用；天空和地形描述寫進地圖檔，組檔時補在最後。
2026-11-25原則十一：不要對泥巴、紋路、泥脊、反光做描寫。地圖檔現有的描述還沒照這條改。
