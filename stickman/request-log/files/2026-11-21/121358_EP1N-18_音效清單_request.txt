你是動畫短片的音效設計。這是一部 2D 卡通短片（粗黑線、平塗色塊的火柴人風格），每一格是一張靜止圖加上旁白，
現在要替其中一場加音效。請照下面每一格的旁白和分鏡寫的動作（畫面裡發生什麼），列出這一場要放哪些聲音、放在第幾秒。
音效清單只看文字決定，不看圖。

## 聲音分四層
1. ambience（環境音）：整段墊底的地點聲音，例如森林、河邊、實驗室的機器嗡嗡聲。一個地點一段，跨好幾格，音量很小。
2. event（事件音效）：畫面裡的東西發出的聲音，例如腳步、恐龍踏步、吼叫、咬合、開門、按按鈕。
3. reaction（角色反應音）：角色只會發出聲音、不會說話（像薩爾達的林克）：喘氣、尖叫、悶哼、「嗯？」。絕對不能有台詞或任何說話的字句。
4. transition（轉場音效）：剪輯手法的聲音，例如定格、倒帶、時間跳轉。

## 規則
- 不是每一格都要有音效，大部分格子應該沒有。事件、反應、轉場音效只放在這一場的「重要位置」：劇情轉折、第一次揭露、高潮、笑點、轉場，
  也就是少了這個聲音觀眾會覺得怪、或戲會變弱的地方。一場通常只有 2～5 個重要位置，沒有就不放。每一個都要在 why 寫出為什麼這裡重要。
- 每一個 cue 都要分成兩種（priority 欄）：
  - must（一定要）：少了它戲就不成立或明顯變弱，例如怪物第一次露面的踏步、高潮的吼叫、定格的轉場音。
  - optional（選擇要）：加了會更好、不加也可以，讓使用者決定要不要，例如持續的腳步聲、喘氣、環境音。
  must 要少而精；拿不準的歸 optional。
- 環境音也不一定要有：只有地點的氣氛重要時才墊（例如追逐的森林），安靜的室內講課可以不放。
- 旁白一定要聽得清楚：旁白講話的時間（每格有寫）裡，只放小聲的聲音（bg、low）；大聲的（吼叫、尖叫、撞擊）放在旁白開始前、句子之間的空檔、或旁白講完之後。
- 時間一律寫「從這一格開始算的秒數」，不要寫整部片的時間；不能超過那一格的長度。可以跨到下一格的，寫 end_shot 和 end。
- 每個聲音要能在真實錄音的免費音效庫（Freesound）找到：給 2～3 組英文搜尋關鍵字，用音效庫的常見說法（例如 "running footsteps mud"、"record scratch"），不要寫很長的句子。
  現實中不存在的聲音（恐龍吼叫、時空門）也先給搜尋關鍵字，另外寫一句 generate_en（給 AI 音效模型的英文描述），音效庫找不到時用。
- 同一種聲音在這一場重複出現（例如腳步聲出現在好幾格），在 sounds 只列一次，在每一格的 cues 引用它的 key。
- 音量只用四級：bg（墊底，幾乎聽不到）、low、mid、high（最大聲，只給高潮的瞬間）。
- 恐龍是跟人差不多大或比人大很多的動物，聲音要有重量；HERO 是一般大學生。
- 不要配樂，配樂另外處理。
- 只能用下面列出的格號；轉場音效可以延續到下一場第一格（end_shot 寫那一格的格號，end 不能超過 1.5 秒）。不要提問，資料不夠的地方照最合理的方式決定，在 notes 寫一句。

## 回傳格式（只回傳這一個 JSON，不要其他文字）
{
 "scene_id": "EP1N-01",
 "notes": "這一場的聲音設計重點（一兩句中文）",
 "sounds": [
  {
   "key": "run_mud",                      ← 英文小寫加底線，這一場內不重複
   "layer": "event",                      ← ambience｜event｜reaction｜transition
   "zh": "泥地奔跑腳步聲",                 ← 中文名稱
   "search_en": ["running footsteps mud", "run mud squelch"],
   "duration_sec": [2, 30],               ← 音效檔長度的合理範圍（秒），搜尋時用
   "loop": true,                          ← 要不要重複接起來鋪滿一段時間（環境音、持續的腳步聲是 true）
   "generate_en": ""                      ← 只有現實不存在、音效庫可能找不到的才寫，否則空字串
  }
 ],
 "cues": [
  {
   "shot": "EP1N-01-01",                  ← 從哪一格開始
   "start": 0.0,                          ← 從這一格開始算第幾秒
   "end_shot": "EP1N-01-05",              ← 到哪一格結束（一次性的短音效：跟 shot 一樣）
   "end": 2.7,                            ← 在 end_shot 那一格的第幾秒結束（一次性的短音效：null，播完為止）
   "sound": "run_mud",                    ← 對到 sounds 的 key
   "priority": "optional",                ← must（一定要）｜optional（選擇要）
   "volume": "mid",                       ← bg｜low｜mid｜high
   "fade_in": 0.0, "fade_out": 0.3,       ← 淡入淡出秒數
   "why": "畫面中 HERO 在泥巴路上狂奔"     ← 中文，為什麼放這個聲音、為什麼放在這一秒
  }
 ]
}

## 這一場：EP1N-18　博士的實驗室（晚上）
入鏡角色：HERO（沒帽子、全身是泥巴、沒背包、躺在地上）；PROF（開心、收照片和牙齒、拿出收據和任務單）

### EP1N-18-01（4.16 秒，這場第 0.00～4.16 秒）
- 旁白：0.00～3.86 秒：「你終於回來了，全身是泥巴，躺在實驗室的地上。」
- 畫面主體：HERO（癱在地上），次要主體 PROF
- 分鏡寫的動作：HERO 四肢攤開癱在地上、虛弱舉著牙和相機的一刻；PROF 俯身大笑。
- 分鏡寫的構圖：HERO 癱在畫面偏右的地上（面朝鏡頭偏左），PROF 站在畫面偏左俯身靠近；背景是北牆時光機圓環。高角度俯視強調 HERO 的狼狽與渺小。

### EP1N-18-02（3.84 秒，這場第 4.16～8.00 秒）
- 旁白：0.00～3.54 秒：「你把牙齒跟照片交給博士，博士開心得不得了。」
- 畫面主體：HERO 與 PROF（交付）
- 分鏡寫的動作：牙齒和相機從 HERO 手中交到 PROF 手上的那一刻，PROF 笑開。
- 分鏡寫的構圖：HERO 在畫面右側地上伸手把牙和相機遞向左側；PROF 在畫面左側彎腰雙手來接。交付動作橫跨畫面中央。

### EP1N-18-03（2.60 秒，這場第 8.00～10.60 秒）
- 旁白：0.00～2.30 秒：「接著，博士把相機翻過來看。」
- 畫面主體：PROF
- 分鏡寫的動作：PROF 把相機翻過來、低頭看它的一刻。
- 分鏡寫的構圖：PROF 置中、胸以上入鏡，雙手在胸前把相機翻轉；框在胸以上，地上的 HERO 落在畫面外。

### EP1N-18-04（5.02 秒，這場第 10.60～15.62 秒）
- 旁白：0.00～4.72 秒：「照片還在，……不過相機嘛，已經不太算是相機了。」
- 畫面主體：摔裂的相機（插入鏡頭）
- 分鏡寫的動作：鏡頭對準相機裂屏上還清楚的暴龍照片、機身卻碎裂變形的那一刻。
- 分鏡寫的構圖：畫面只有一台摔裂的相機，由兩隻手（PROF 的手）捧在正中央；裂開的螢幕還亮著暴龍照片。高角度俯看手中物。

### EP1N-18-05（4.24 秒，這場第 15.62～19.86 秒）
- 旁白：0.00～3.94 秒：「然後，他從信封裡把鈔票抽走，換成一張收據。」
- 畫面主體：PROF
- 分鏡寫的動作：鈔票被抽出信封、收據塞進去的交換瞬間，PROF 偷笑。
- 分鏡寫的構圖：PROF 置中、腰以上入鏡，一手拿信封、一手把鈔票抽出來並塞進收據；HERO 在畫面外。

### EP1N-18-06（4.88 秒，這場第 19.86～24.74 秒）
- 旁白：0.00～4.58 秒：「收據上畫著：一台壞掉的相機，還有一把電擊槍。……」
- 畫面主體：收據（插入鏡頭）
- 分鏡寫的動作：鏡頭對準收據上那兩個小圖示的一刻，資訊笑點。
- 分鏡寫的構圖：畫面只有一張收據，由兩隻手（PROF 的手）捧在正中央；收據上只手繪兩個小圖示：壞相機和電擊槍，沒有字。高角度俯看。

### EP1N-18-07（3.24 秒，這場第 24.74～27.98 秒）
- 旁白：0.00～2.94 秒：「這樣算下來，你反而還倒欠博士錢。」
- 畫面主體：HERO

- 分鏡寫的構圖：HERO 的臉置中、胸以上入鏡（滿臉泥），平視（相機放低到他躺著的視線高度）。死魚臉收笑點。

### EP1N-18-08（2.84 秒，這場第 27.98～30.82 秒）
- 旁白：0.00～2.54 秒：「接著，他又拿出下一張任務單。」

- 分鏡寫的動作：PROF 把下一張任務單抽出來、得意舉起的一刻。
- 分鏡寫的構圖：PROF 置中、腰以上入鏡，從外套掏出下一張任務單舉起來；HERO 在畫面外。

### EP1N-18-09（3.20 秒，這場第 30.82～34.02 秒）

- 分鏡寫的構圖：畫面只有一張任務單，由兩隻手（PROF 的手）捧在正中央；上面只畫一顆拖著長尾巴的亮星，沒有字。高角度俯看。

### EP1N-18-10（5.02 秒，這場第 34.02～39.04 秒）
