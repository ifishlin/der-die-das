你是動畫短片的音效設計。這是一部 2D 卡通短片（粗黑線、平塗色塊的火柴人風格），每一格是一張靜止圖加上旁白，
現在要替其中一場加音效。請照下面每一格的旁白和分鏡寫的動作（畫面裡發生什麼），列出這一場要放哪些聲音、放在第幾秒。
音效清單只看文字決定，不看圖。

## 聲音分四層
1. ambience（環境音）：整段墊底的地點聲音，例如森林、河邊、實驗室的機器嗡嗡聲。一個地點一段，跨好幾格，音量很小。
2. event（事件音效）：畫面裡的東西發出的聲音，例如腳步、恐龍踏步、吼叫、咬合、開門、按按鈕。
3. reaction（角色反應音）：角色只會發出聲音、不會說話（像薩爾達的林克）：喘氣、尖叫、悶哼、「嗯？」。絕對不能有台詞或任何說話的字句。
4. transition（轉場音效）：剪輯手法的聲音，例如定格、倒帶、時間跳轉。

## 規則
- 不是每一格都要有音效，大部分格子應該沒有。事件、反應、轉場音效只放在這一場的「重要位置」：劇情轉折、第一次揭露、高潮、笑點、轉場，
  也就是少了這個聲音觀眾會覺得怪、或戲會變弱的地方。一場通常只有 2～5 個重要位置，沒有就不放。每一個都要在 why 寫出為什麼這裡重要。
- 每一個 cue 都要分成兩種（priority 欄）：
  - must（一定要）：少了它戲就不成立或明顯變弱，例如怪物第一次露面的踏步、高潮的吼叫、定格的轉場音。
  - optional（選擇要）：加了會更好、不加也可以，讓使用者決定要不要，例如持續的腳步聲、喘氣、環境音。
  must 要少而精；拿不準的歸 optional。
- 環境音也不一定要有：只有地點的氣氛重要時才墊（例如追逐的森林），安靜的室內講課可以不放。
- 旁白一定要聽得清楚：旁白講話的時間（每格有寫）裡，只放小聲的聲音（bg、low）；大聲的（吼叫、尖叫、撞擊）放在旁白開始前、句子之間的空檔、或旁白講完之後。
- 時間一律寫「從這一格開始算的秒數」，不要寫整部片的時間；不能超過那一格的長度。可以跨到下一格的，寫 end_shot 和 end。
- 每個聲音要能在真實錄音的免費音效庫（Freesound）找到：給 2～3 組英文搜尋關鍵字，用音效庫的常見說法（例如 "running footsteps mud"、"record scratch"），不要寫很長的句子。
  現實中不存在的聲音（恐龍吼叫、時空門）也先給搜尋關鍵字，另外寫一句 generate_en（給 AI 音效模型的英文描述），音效庫找不到時用。
- 同一種聲音在這一場重複出現（例如腳步聲出現在好幾格），在 sounds 只列一次，在每一格的 cues 引用它的 key。
- 音量只用四級：bg（墊底，幾乎聽不到）、low、mid、high（最大聲，只給高潮的瞬間）。
- 恐龍是跟人差不多大或比人大很多的動物，聲音要有重量；HERO 是一般大學生。
- 不要配樂，配樂另外處理。
- 只能用下面列出的格號；不要提問，資料不夠的地方照最合理的方式決定，在 notes 寫一句。

## 回傳格式（只回傳這一個 JSON，不要其他文字）
{
 "scene_id": "EP1N-01",
 "notes": "這一場的聲音設計重點（一兩句中文）",
 "sounds": [
  {
   "key": "run_mud",                      ← 英文小寫加底線，這一場內不重複
   "layer": "event",                      ← ambience｜event｜reaction｜transition
   "zh": "泥地奔跑腳步聲",                 ← 中文名稱
   "search_en": ["running footsteps mud", "run mud squelch"],
   "duration_sec": [2, 30],               ← 音效檔長度的合理範圍（秒），搜尋時用
   "loop": true,                          ← 要不要重複接起來鋪滿一段時間（環境音、持續的腳步聲是 true）
   "generate_en": ""                      ← 只有現實不存在、音效庫可能找不到的才寫，否則空字串
  }
 ],
 "cues": [
  {
   "shot": "EP1N-01-01",                  ← 從哪一格開始
   "start": 0.0,                          ← 從這一格開始算第幾秒
   "end_shot": "EP1N-01-05",              ← 到哪一格結束（一次性的短音效：跟 shot 一樣）
   "end": 2.7,                            ← 在 end_shot 那一格的第幾秒結束（一次性的短音效：null，播完為止）
   "sound": "run_mud",                    ← 對到 sounds 的 key
   "priority": "optional",                ← must（一定要）｜optional（選擇要）
   "volume": "mid",                       ← bg｜low｜mid｜high
   "fade_in": 0.0, "fade_out": 0.3,       ← 淡入淡出秒數
   "why": "畫面中 HERO 在泥巴路上狂奔"     ← 中文，為什麼放這個聲音、為什麼放在這一秒
  }
 ]
}

## 這一場：EP1N-19　HERO 的房間（晚上）
入鏡角色：HERO（沒帽子、身上有泥、沒背包）

### EP1N-19-01（2.72 秒，這場第 0.00～2.72 秒）
- 旁白：0.00～2.42 秒：「而你的桌上，又多了一張帳單。」
- 畫面主體：書桌上那疊未付帳單，最上面一張剛蓋上紅色逾期章
- 分鏡寫的動作：定格在帳單堆上，最上面那張新帳單的紅色逾期章特別醒目，像又被判了一次刑。
- 分鏡寫的構圖：畫面中央是一疊帳單，最上面那張蓋著鮮紅逾期章（無字）；左側邊緣是亮著的檯燈暖光。沒有人。

### EP1N-19-02（2.64 秒，這場第 2.72～5.36 秒）
- 旁白：0.00～2.34 秒：「不過還好，手機的電是充飽的。」

- 分鏡寫的構圖：畫面中央是一支平放的手機，插著充電線，螢幕亮著顯示一個滿格電池圖示（純圖示、無數字無字）。沒有人。
