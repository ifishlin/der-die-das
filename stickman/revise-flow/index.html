Flow 畫完之後

2026-11-13 改定。先改 prompt 重畫，再選圖。

第 1 步：你挑出 prompt 要改的格子

  • 你在分鏡表挑出 prompt 要改的格子，給我指示（按「表達不好，要重寫 prompt」，寫下要怎麼改）。
  • 我照你的指示改 prompt，這格重新生圖。

第 2 步：選圖（第 1 步結束後）

  • 我每格從 4 張挑出一張最合適的，在分鏡表標「Claude 建議」。不用判斷是 prompt 錯還是生圖錯，只挑最好的那張。
  • 挑的時候考慮（照優先順序；每格先看原尺寸圖、把 4 張逐項的檢查結果寫下來，再決定）：
    • 1. 不該出現的東西（優先）：對照地圖視野和背景描述：有沒有多出地圖上沒有、或這個方向看不到的東西（多一個角色、多一隻恐龍、多一扇門或窗、降落點看到河、室內出現戶外景）。
    • 2. 該出現的主要東西有沒有：入鏡角色都在；這格的主要物件在（時光機圓環、黑板、甲龍「石頭」、時光門等）。
    • 3. 長相、道具跟參考圖一致：打開 REF 圖並排對照：HERO（探險帽、圓眼鏡、帽 T、背心、白臉）、博士（白亂髮、護目鏡、紅領結、白袍）、恐龍種類、道具（REF_PROPS）。prompt 寫的跟參考圖不同時，以參考圖為準。
    • 4. 恐龍大小：不用 Claude 自己的判斷，直接用 Codex 和 Claude CLI 的回答（見下方）：兩邊都說一致，或要調的倍數最小的優先。
  • 不拿來挑的：左右方向、牆角在畫面哪裡、角色面向、景別鬆緊（Claude 判不準）；畫壞、戲劇張力（你自己看）。
  • 你根據我的建議和你自己的判斷選圖。分鏡表每格只能選一張，選的是要留下來的。
  • 一格都沒選＝四張都不行，整格重畫。

恐龍大小：問 Codex 和 Claude CLI

  • 每張「有 HERO 又有恐龍」的圖（照分鏡的入鏡角色挑；鴨嘴龍很多隻，不問），一幕一份 request，同時問 Codex 和 Claude CLI（不是主對話的 Claude）。超過 8 格的幕拆成 a、b 兩份。
  • 附這一幕用到的站姿比例圖 PAIR_<恐龍>（甲龍也用站姿），跟每張圖並排目視：一致、偏小、偏大；不量像素、不用公式、不用地圖距離，要考慮遠近和姿勢，局部鏡頭用看得到的部位比。
  • 偏小或偏大時回答要放大／縮小幾倍，只能選 1.2、1.4、1.6、1.8、2.0；差不到 1.2 倍算一致，超過 2 倍填 2.0。
  • 兩邊的答案標在分鏡表每張圖上。程式：scripts/make_size_ask_v7.py（產生 request）、scripts/send_size_ask_v7.py（送出）。
