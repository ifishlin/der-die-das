Flow 畫完之後

2026-11-13 改定。先改 prompt 重畫，再選圖。

第 1 步：你挑出 prompt 要改的格子

  • 你在分鏡表挑出 prompt 要改的格子，給我指示（按「表達不好，要重寫 prompt」，寫下要怎麼改）。
  • 我照你的指示改 prompt，這格重新生圖。

第 2 步：選圖（第 1 步結束後）

  • 我每格從 4 張挑出一張最合適的，在分鏡表標「Claude 建議」。不用判斷是 prompt 錯還是生圖錯，只挑最好的那張。
  • 挑的時候考慮：
    • 背景是否符合地圖：對照這格的地圖和相機視野：該看到的有、不該看到的沒有，左右位置跟地圖一致。
    • 人物、物品是否符合參考圖：對照 REF_<角色>、REF_PROPS、牆面圖（ROOM_*／LAB_*）：長相、衣著、道具、場景擺設跟參考圖一致。
    • 恐龍 size 是否吻合：跟比例圖 PAIR_<恐龍> 並排目視，大小關係一致。
  • 你根據我的建議和你自己的判斷選圖。分鏡表每格只能選一張，選的是要留下來的。
  • 一格都沒選＝四張都不行，整格重畫。
