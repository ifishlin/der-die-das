檢查文件的格式與資料來源

第 2～18 步的七份檢查文件，每個欄位從哪個資料檔的哪個欄位來、資料檔由誰產生、格式是什麼。來源：docs/page_spec.json（第 1 版，2026-11-19）。

規定

  • 頁面上每一個欄位都要對到一個資料檔的一個欄位；對不到的不准寫進頁面。
  • 資料檔只能有這裡列的欄位；多了、少了，產生頁面的程式就報錯、不產生頁面。
  • request 的回傳格式＝資料檔格式；我手寫的資料也照同樣固定格式填，不准自由寫。
  • 程式只搬運和計算（統計、比對新舊、檢查網址、畫地圖），不寫內容。
  • 頁面不放：要你決定／待定事項／問題清單、版本說明、★、附註、秒數。模型或我要問的事在對話裡問。

關係圖

request 送 Claude CLI，照範本，回覆存成資料檔　我 Claude 在對話裡照固定格式寫進資料檔（分工本來就是我做的步驟）　你 使用者決定或寫的　程式 程式計算或搬運，不寫內容　Flow Google Flow 畫出來的圖和連結
