新鏡頭用語測試規劃

2026-11-10。測 docs/shot_terms.md 的新用語，Nano Banana（Google Flow）認不認得。

  • 測試的鏡頭：EP1 S00-3（黃昏森林小路，青少年暴龍追主角），跟 2026-11-07 的舊景別測試同一幕，新舊才能比。
  • 原則：一次只改一個條件；其他句子盡量跟舊測試一字不差。只有方向會打架的組（側面、背面、主觀、過肩）才換掉動作句，原因寫在該組。
  • 每個 prompt 出 4 張（跟舊測試一樣）。
  • 順序照攝影原理的重要性：拍多大 → 相機高低與方向 → 左右與方向 → 從哪一邊拍 → 用誰的眼睛看。
  • 第一階段：五組都單獨測（不組合），共 21 個 prompt、84 張。第二階段：看完結果再做組合，先列 3 個。

邏輯檢查

產生器（scripts/make_terms_test.py）對每個 prompt 自動檢查：朝鏡頭跑不能配側面／背面、只有 TEEN 時不能寫 HERO 外型、只能有一個景別、不能寫百分比。全部通過才會輸出。

另外人工確認過的：

  • 背面、後側 3/4 看不到臉，所以 B 組動作句不寫尖叫、張嘴；結尾句把「臉和手是純白」改成「皮膚是純白」（B、D、過肩都用這一句，同一組內一致）。
  • 背面時暴龍比主角高、又在相機和主角之間，會把主角整個擋住；所以背面加一句「暴龍跑在小路一側，不擋住主角」。
  • A 組跟舊測試比，除了景別那一行，舊的「Camera angle」一行也拆成方位、高度＋角度兩行（新用語本來就是這樣寫）。
  • 只拍眼睛（A-ECU）時 TEEN、胸前相機、比例圖都不會入鏡，所以拿掉那幾句，只附 REF_HERO。
  • 主觀（E-pov）主角不入鏡，所以不寫主角外型、相機、比例。
  • 過肩選「從暴龍肩後看主角」，因為從主角肩後看暴龍需要主角轉身，跟這一幕主角在逃跑衝突。
  • C 組的基準「眼高＋水平」跟 A-FS 是同一個 prompt，不重複畫。
