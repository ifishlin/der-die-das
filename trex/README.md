# 成年暴龍動作總覽：新版草圖

直接開啟 `index.html`，可在同一頁預覽跑步、轉身、擺尾、表情、嘴型和眨眼。支援播放／暫停、逐格、變速、水平翻轉；轉身可反向播放。所有獨立畫格為 768×512 透明 PNG。

| 動作 | 畫格 | 狀態 |
|---|---:|---|
| 跑步 | 16 | 保留核准的配色修正版 |
| 轉身 | 5 | 正面格修短頸部的草圖 |
| 擺尾 | 6 | 四張 1536×1024 單格原稿縮小輸出，往返成六格 |
| 表情 | 9 | 依新版頭型重畫；「開心」的牙齒下方已修為透明空隙 |
| 嘴型 | 6 | 閉合到張開再閉合；「微開、中開」往返畫格的下顎已修正 |
| 眨眼 | 3 | 重用表情第 07–09 格 |

`sources/` 保存生成原稿，擺尾使用 `tail_hd_00.png`–`tail_hd_03.png`，三張下顎修正圖以 `*_jaw_fixed.png` 命名。`build_assets.sh` 負責清除背景雜點、縮小至統一畫布、校正主色，並重建 `frames/`、`sheets/` 與 `review/`。`manifest.json` 記錄播放順序和來源。舊版完整保留於相鄰的 `adult_trex_actions_hub/`；修正前素材包保留在相鄰的 `*_before_*_fix.zip`。

這些動作仍是待逐格審核的草圖；頭部表情和嘴型是獨立肖像畫格，沒有合成到全身。詳見 `CHARACTER_AUDIT.md`。
